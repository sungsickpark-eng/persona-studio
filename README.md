# Persona Story Studio

"상황을 던져보세요. 대사는 캐릭터가 자신의 방식으로 선택합니다."

세계관·캐릭터·집단·관계·사실을 설정해두면, 그 설정에 진짜로 묶인 채로 캐릭터를 인터뷰하거나(정보 비대칭·성격·관계에 따라 다르게 반응) AI가 전지적 작가 시점으로 소설을 이어 써주는 캐릭터 시뮬레이션·창작 도구입니다. 모든 데이터는 브라우저 로컬에만 저장되고, AI는 로컬 LLM(Ollama) 또는 OpenAI/Google Gemini/Claude API 중 골라 쓸 수 있습니다.

## 설치

### 요구 사항

- Node.js 20 이상
- 다음 중 최소 하나
  - **로컬 LLM**: [Ollama](https://ollama.com) 설치 후 원하는 모델 하나 이상 받아두기 (기본값: `ollama pull gemma4`)
  - **클라우드 API 키**: OpenAI, Google Gemini, Anthropic Claude 중 사용할 서비스의 API 키

### 의존성 설치

```bash
npm install
```

### 환경변수 (선택)

로컬 LLM(Ollama)의 서버 주소·기본 모델을 기본값과 다르게 쓰고 싶을 때만 프로젝트 루트에 `.env.local`을 만드세요. 없어도 기본값(`http://localhost:11434`, `gemma4:latest`)으로 동작합니다.

```bash
# .env.local
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=gemma4:latest
```

클라우드 API 키(OpenAI/Gemini/Claude)는 `.env` 파일이 아니라 **앱 안의 "설정" 도구**에서 입력합니다 (아래 [AI 연동 설정](#ai-연동-설정) 참고). 브라우저 로컬에만 저장되고, 요청할 때만 로컬 서버를 거쳐 해당 API로 전달됩니다.

## 실행

```bash
# 개발 서버
npm run dev

# 프로덕션 빌드 + 실행
npm run build
npm start
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 을 엽니다.

## AI 연동 설정

헤더의 **"설정 · (현재 AI)"** 버튼을 누르면 캐릭터 시뮬레이션·이야기 생성에 쓸 AI를 고를 수 있습니다.

| 옵션 | 필요한 값 | 비고 |
|---|---|---|
| 로컬 LLM (Ollama) | 서버 주소 (기본 `http://localhost:11434`) | 어떤 모델을 쓸지는 헤더의 별도 **"모델"** 버튼에서 설치된 모델 중 고르거나, 카탈로그(Llama/Gemma/Qwen/Mistral 등)에서 바로 다운로드 |
| OpenAI | API 키, API 주소(기본값 있음), 모델명(예: `gpt-4o-mini`) | |
| Google Gemini | API 키, API 주소(기본값 있음), 모델명(예: `gemini-2.0-flash`) | |
| Claude | API 키, API 주소(기본값 있음), 모델명(예: `claude-sonnet-5`) | |

키·주소는 이 브라우저(localStorage)에만 저장됩니다. 로컬 LLM을 고르면 인터넷 연결 없이도 완전히 오프라인으로 쓸 수 있습니다.

> ⚠️ **비용 안내**: OpenAI/Google Gemini/Claude 같은 클라우드 API는 사용량에 따라 요금이 청구될 수 있습니다. 발생하는 비용은
> 그 API 키 소유자 본인 책임이며, 이 프로젝트와 개발자는 어떠한 책임도 지지 않습니다. 사용 전 해당 서비스의 요금제·사용 한도를
> 직접 확인하세요. 로컬 LLM(Ollama)은 무료입니다.

## 빠른 시작

1. 첫 화면(`/`)에서 프로젝트 이름을 입력하고 "만들기" — 프로젝트 목록에 카드가 생깁니다.
2. 프로젝트를 열고 헤더의 "설정"에서 AI를 하나 고릅니다 (로컬 LLM이면 "모델" 버튼에서 모델도 하나 받아둡니다).
3. **세계관** 탭에서 시대/배경, 힘의 근원, 금기 등 기본 설정을 채웁니다 (전부 비워둬도 진행은 가능).
4. **캐릭터** 탭에서 캐릭터를 한 명 이상 만듭니다.
5. **인터뷰** 탭에서 캐릭터를 골라 말을 걸어봅니다.
6. 화면 아래 **이야기 쓰기** 창에서 "다음 상황 제안받기"를 눌러 AI가 제안하는 전개 중 하나를 골라 이어 써봅니다.

## 화면 구성

프로젝트를 열면 다음과 같이 구성됩니다.

- **헤더**: 설정(AI 연동) · 모델(로컬 LLM일 때만) · Obsidian 내보내기 버튼
- **타임라인**: 지금까지 쓴 이야기에 "2026년", "3월" 처럼 등장한 날짜를 자동으로 인식해 시간순으로 점 찍어 보여줌
- **관계도**: 화면 대부분을 차지하는 지도 형태의 인물·집단 관계 그래프 (자세한 조작법은 [관계도](#관계도) 참고)
- **이야기 쓰기**: 관계도 아래 항상 떠 있는 패널 — 팝업을 열지 않고 바로 다음 이야기를 이어 씀
- **탭 메뉴**: 세계관 / 사실·비밀 / 캐릭터 / 집단 / 관계 / 인터뷰 / 떡밥 / 승인함 / 삭제됨 — 클릭하면 팝업으로 뜸

## 탭별 사용법

### 세계관

시대·장소, 자연 법칙, 힘의 근원(마법/기술)과 그 대가·한계, 지배 구조·신분제·법, 지리·의식주·경제, 역사·대립·금기, 종교·도덕·속어까지 5개 대분류로 나뉜 자유 서술 항목들. AI가 캐릭터를 연기하거나 이야기를 쓸 때 이 설정 밖의 내용을 임의로 만들지 않도록 프롬프트에 그대로 들어갑니다.

### 사실·비밀

작가만 아는 "진짜 사실"을 등록하고, 캐릭터별로 공개 범위를 지정합니다.

- **앎** — 처음부터 알거나, 특정 챕터부터 알게 됨(중간에 알게 되는 시점 지정 가능)
- **모름** — 끝까지 모름 (프롬프트에 아예 포함되지 않아 AI가 절대 언급하지 않음)
- **오해함** — 실제와 다른 내용을 진실이라 믿음 (예: 범인이 아닌데 범인이라 믿음)

### 캐릭터

이름·나이·직업·외형 요약, 성격·가치관·말투, 배경 서사, 현재 목표, 과거/현재/미래 지향점, 금기·트리거, 캐릭터 디자인 이미지(업로드 시 자동 압축 + 자르기 위치 조절)를 관리합니다. 생성 시 소속 집단을 바로 체크할 수 있고, 상세 화면에서도 소속을 켜고 끌 수 있습니다. 승인된 추가 설정은 "승인된 추가 설정" 목록에 누적됩니다.

### 집단

이름·설명(성격/목적/규율 등), 구성원, 상위 집단(학교 > 학년 > 학급처럼 트리 구조, 순환 지정은 자동 차단)을 관리합니다. 상위 집단을 지정하면 그 사이에 기본 관계(아는 사이, 50점)가 자동 생성됩니다.

### 관계

세 종류의 관계를 각각 관리합니다.

- **캐릭터 간 관계**: 1~100점(20 미만 적대·40 미만 경계·60 미만 중립·80 미만 우호·이상 각별), 서로의 존재를 아예 모르는 상태로도 지정 가능, 양방향(기본) 또는 단방향(짝사랑처럼 한쪽만 그 감정을 가짐)
- **집단 간 관계**: 캐릭터 간과 동일한 점수 체계
- **캐릭터-집단 관계**: 소속 여부와 무관하게(예: "이 조직이 감시 중인 외부인") 캐릭터 쪽/집단 쪽 인지 여부를 각각 따로 지정 가능(비대칭 관계)

모든 관계는 인터뷰·이야기 쓰기 프롬프트에 그대로 반영되어, 관계가 나쁜 상대를 언급하면 캐릭터가 실제로 경계하거나 적대적으로 반응합니다.

### 인터뷰

캐릭터를 한 명 골라 대화합니다.

- **페르소나 강도 1~4**: 1(자유로운 브레인스토밍) ~ 4(완전 몰입, 설정 밖 지식 절대 사용 안 함)
- **시점 선택**: 특정 챕터를 고르면 그 챕터까지 알게 된 사실만 반영(정보 비대칭 시뮬레이션), 안 고르면 모든 공개된 사실을 다 아는 것으로 취급
- 응답은 **겉으로 하는 말(대사)** 과 **속마음**이 분리되어 표시됩니다
- 대화 중 캐릭터가 즉흥적으로 새 설정을 제안하면 **승인함** 탭에 쌓이고, 작가가 승인해야 공식 설정이 됩니다

### 떡밥

[떡밥(복선) 관리](#떡밥복선-관리) 참고.

### 승인함

인터뷰 중 캐릭터가 즉흥적으로 제안한 설정을 모아 보여줍니다. 승인하면 그 캐릭터의 "승인된 추가 설정" 목록에 반영되고, 거절하면 사라집니다.

### 삭제됨

캐릭터·집단을 삭제하면 실제로는 지워지지 않고 휴지통으로 이동합니다(소속·관계·사실 공개 범위 등 연결된 데이터가 모두 보존됨). 여기서 복구하거나 영구 삭제할 수 있습니다.

## 관계도

화면 대부분을 차지하는 지도 형태의 그래프입니다.

- 원(캐릭터, 디자인 이미지가 있으면 클립되어 보임)과 보라색 알약(집단)으로 표시
- **노드를 드래그**해서 다른 노드 위에 놓으면: 캐릭터↔집단이면 소속을 토글, 같은 종류끼리면 관계를 새로 만들거나 지움
- **노드를 클릭**(거의 움직이지 않고 뗌)하면 해당 캐릭터/집단의 설정 팝업이 바로 열림
- 관계선은 점수에 따라 색이 바뀌고, 항상 점수 숫자가 라벨로 붙어 있음(단방향 관계는 화살표로 표시)
- 상하위 집단은 들여쓰기 + 얇은 실선으로 표시(관계선과는 구분됨)
- 우상단 +/- 버튼으로 확대/축소

## 이야기 쓰기

관계도 아래 항상 떠 있는 패널로, "전지적 작가" 시점에서 세계관 전체(모든 인물·집단·관계·사실)를 참고해 이야기를 이어 씁니다(인터뷰와 달리 정보 비대칭을 걸러내지 않음).

- **다음 상황 제안받기**: 서로 다른 전개 3가지를 제안받아 클릭 한 번으로 채택
- **직접 입력**: 원하는 전개를 타이핑해서 바로 이어 쓰기
- 새로 추가된 내용은 설정과 충돌하는 부분이 없는지 자동으로 검사되어, 문제가 있으면 경고로 표시(글쓰기 자체를 막지는 않음)
- **되돌리기**: 세션 동안(새로고침하면 초기화) 최대 N회까지 직접 편집·이어쓰기를 되돌릴 수 있음
- **챕터**: 왼쪽 챕터 구성 트리에서 막/장을 만들고, 카드를 클릭하면 그 챕터의 내용만 보면서 이어 쓸 수 있음(이어 쓴 내용도 자동으로 그 챕터로 태그됨)
- **이야기 내보내기**: 지금 이어 쓰고 있는 줄기를 파일로 저장 (Obsidian 내보내기와 같은 폴더 구조)

## 떡밥(복선) 관리

이야기 쓰기 중 문구를 드래그로 선택하고 "떡밥 설정"을 누르면 그 지점이 떡밥으로 등록됩니다. 나중에 다른 문구를 선택해 "떡밥N 회수"를 고르면 그 떡밥이 회수 처리됩니다.

- 설정/회수된 문구는 본문 안에서 **형광펜처럼 색이 칠해져** 바로 눈에 띕니다(호박색=설정, 에메랄드색=회수)
- 각 지점 아래 작은 배지로도 "떡밥N 설정" / "떡밥N 회수"가 표시되고, 배지의 ✕로 각각 삭제·회수 취소 가능
- **떡밥 탭**을 열면 전체 목록을 한눈에 볼 수 있고, 설정/회수 문구를 클릭하면 이야기 쓰기 창에서 그 지점으로 바로 스크롤 이동
- 떡밥 탭에서 삭제(설정+회수 전체 삭제) 또는 **회수 취소**(설정은 남기고 회수만 취소)가 가능

## Obsidian 내보내기

헤더의 "Obsidian 내보내기 (폴더)"를 누르면 폴더를 선택할 수 있고(Chrome/Edge 전용, File System Access API), 그 안에 프로젝트명 폴더를 만들어 인물·집단을 각각 개별 `.md` 노트로 저장합니다.

- 본문에서 다른 인물/집단 이름이 등장하면 자동으로 `[[위키링크]]`로 치환됨
- 캐릭터 디자인 이미지는 `디자인/` 폴더에 저장되고 `![[파일명]]`으로 임베드됨
- 그대로 Obsidian 볼트로 열어 쓸 수 있음

## 데이터는 어디에 저장되나요

모든 프로젝트 데이터(세계관·캐릭터·집단·관계·사실·대화·이야기)는 **이 브라우저의 localStorage에만** 저장됩니다. 서버로 전송되거나 백업되지 않으므로:

- 다른 브라우저·기기에서는 보이지 않습니다
- 브라우저 데이터를 지우면 함께 사라집니다 — 중요한 프로젝트는 주기적으로 Obsidian/이야기 내보내기로 백업하세요
- AI 연동 설정(API 키 포함)도 같은 방식으로 이 브라우저에만 저장됩니다

## 문제 해결

- **"Ollama에 연결할 수 없습니다"** — `ollama serve`가 실행 중인지, 설정에 입력한 서버 주소가 맞는지 확인하세요.
- **"OpenAI/Gemini/Claude API 키가 설정되지 않았습니다"** — 헤더의 "설정"에서 해당 서비스 API 키를 입력하세요.
- **"OpenAI/Gemini/Claude API에 연결할 수 없습니다"** — 인터넷 연결과 설정에 입력한 API 주소·키를 확인하세요.
- **Obsidian 내보내기 버튼을 눌러도 반응이 없다** — 폴더 선택 기능은 Chrome/Edge 등 Chromium 계열 브라우저에서만 지원됩니다.
- **어제까지 있던 프로젝트가 안 보인다** — 다른 브라우저(또는 시크릿 모드)로 열지는 않았는지 확인하세요. 데이터는 브라우저별로 완전히 분리됩니다.
